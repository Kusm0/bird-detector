# Bird detector (YOLO26n)

Детекція птахів на зображеннях і відео. Модель `yolo26n` (Ultralytics), донавчена на одному класі `bird`
на підвибірці COCO 2017.

```
bird-detector/
├── README.md
├── requirements.txt
├── prepare_dataset.py   # завантаження COCO (лише bird) -> YOLO, split train/val
├── train.py             # навчання
├── predict_video.py     # інференс на відео
├── weights/
│   ├── best.pt          # найкращі ваги
│   └── metrics.json     # метрики на validation
└── examples/
    ├── input.mp4        # вхідне відео
    ├── output.mp4       # результат
    ├── images/          # приклади передбачень моделі на validation-зображеннях
    └── training/        # графіки та results.csv навчання, метрики baseline
```

## Встановлення

Потрібен Python 3.10+ (перевірено на 3.11).

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Підготовка датасету

```bash
python prepare_dataset.py
```

Скрипт завантажує через FiftyOne лише зображення COCO 2017 з птахами (не весь датасет), залишає лише клас `bird`,
ігнорує crowd-розмітку, випадково ділить 80/20 (seed=42) і створює `datasets/bird/dataset.yaml`.

## Навчання

```bash
python train.py
```

Параметри за замовчуванням: старт з `yolo26n.pt`, 40 епох, `imgsz=512`, batch 16, early stopping `patience=15`;
пристрій обирається автоматично (CUDA / Apple MPS / CPU). Результат копіюється у `weights/best.pt`,
метрики на validation — у `weights/metrics.json`. Це саме та конфігурація, якою отримано ваги з цього репозиторію
(MacBook, 8 ГБ RAM, Apple MPS: `python train.py --device mps`).

Параметри змінюються аргументами, наприклад: `python train.py --epochs 100 --imgsz 640 --batch 32`.

## Обробка відео

```bash
python predict_video.py --input examples/input.mp4 --output examples/output.mp4
```

Необов'язкові параметри: `--weights` (за замовчуванням `weights/best.pt`), `--conf` (поріг, 0.25), `--imgsz` (512, як при навчанні), `--device`.
На кожному кадрі малюється bounding box із підписом `bird <confidence>`; результат записується у файл.

## Датасет

- Джерело: [COCO 2017](https://cocodataset.org) (детекція), клас `bird`; розмітка перетворена у YOLO-формат.
- Вибірка: 3125 зображень COCO з птахами, відібраних випадково (`--max-samples 3000`, seed=42).
- Розбиття: **train 2500 зображень / 8174 боксів**, **val 625 зображень / 2002 бокси**.
- Розмітка COCO: CC BY 4.0, зображення — Flickr (ліцензії окремих знімків різні, див. сайт COCO).
- Демо-відео: Pexels, "Flying seagulls slow motion" (ліцензія Pexels), обрізано до 15 с, 720×1280, 30 fps.

## Результати на validation

Метрики `weights/best.pt` (найкраща епоха 39 з 40), 625 зображень, `imgsz=512`:

| Precision | Recall | mAP50 | mAP50-95 |
|---|---|---|---|
| 0.662 | 0.486 | 0.546 | 0.328 |

Для порівняння, baseline з тими самими налаштуваннями, але 15 епох: P 0.635, R 0.465, mAP50 0.522, mAP50-95 0.310.
Графіки навчання: `examples/training/results.png`, `BoxPR_curve.png`, `confusion_matrix.png`.

На демо-відео (450 кадрів, 2462 детекції) модель виділяє кількох чайок на кадрі одночасно, зокрема частково обрізаних краєм кадру;
за вибірковими кадрами confidence варіюється від ≈0.35 до ≈0.9.

## Проблеми та можливі покращення

- **Обмеження обладнання.** Навчання з `imgsz=640` на Mac із 8 ГБ RAM впиралося у своп (≈19 с на ітерацію), тому використано `imgsz=512`.
  Це знижує якість для дрібних птахів. На GPU варто тренувати на 640 і більше.
- **Невисокий recall (≈0.49).** Птахи в COCO часто дрібні, розмиті або частково закриті; частину з них модель пропускає.
  mAP50-95 росла повільно до кінця (0.317 на 30-й епосі, 0.327 на 40-й), тож довше навчання дало б лише невеликий приріст;
  основне обмеження — розмір моделі, роздільна здатність і дані.
- **Метрики оптимістичні.** `best.pt` вибирається за тією ж validation-вибіркою, на якій рахуються метрики.
  Краще мати окрему test-вибірку.
- **Домен.** COCO — переважно фото на землі та в побуті; на відео з іншими умовами (далекі зграї, нічні кадри) якість може бути нижчою.
- **Покращення:** більша модель (`yolo26s/m`), додаткові датасети (Open Images, CUB-200, Roboflow Universe),
  `imgsz` 640–960 та тайлінг (SAHI) для дрібних птахів, окрема test-вибірка, підбір порога `--conf` за F1-кривою,
  трекінг (ByteTrack) для стабільних ID між кадрами.
